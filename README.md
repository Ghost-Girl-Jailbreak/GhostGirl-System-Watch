## 🌌 About

</div>

**GhostGirl System Watch** is a hardware monitoring app for jailbroken Xbox 360 consoles. It shows live temperatures and lets you control fan speed — all from your console.

Part of the [Project Ghost Girl](https://github.com/Ghost-Girl-Jailbreak/Project-Ghost-Girl) app store.

<div align="center">

| Feature | Description |
|:---|:---|
| 🌡️ **Live Temps** | CPU, GPU, and EDRAM temperatures in real time |
| 🌀 **Fan Speed** | View current fan speed percentage |
| ⚙️ **Manual Control** | Set fan speed from 20% to 100% |
| 📊 **Simple UI** | Controller-friendly, readable from the couch |
| 🚫 **No Telemetry** | Runs entirely on-console |

</div>

> ⚠️ **Requires a jailbroken Xbox 360** running ABadUpdate or ABadAvatar.

## 📥 Install

</div>

### ⭐ Recommended — Install via Project Ghost Girl App Store

The easiest way to install **GhostGirl System Watch** is through the
**Project Ghost Girl app store** on your console.

- ✅ Automatic downloads
- ✅ One-click install
- ✅ Always get the latest version
- ✅ No manual file management

Just open the store on your jailbroken console, find **System Watch**
in the app list, and hit install. Done.

### 🛠️ Manual Download (Not Recommended)

If you can't use the app store, you can install manually:

1. Download `SystemWatch.xex` from the [Releases](../../releases) page.
2. Place it in `Hdd:\Apps\SystemWatch\` on your console.
3. Launch it from your dashboard.

> ⚠️ **We recommend using the app store instead.** Manual installs
> mean you have to check for updates yourself, and you might miss
> important fixes. The store handles everything automatically.

## 🚀 Features

</div>

### Temperature Monitoring

- **CPU** — the main processor temperature
- **GPU** — the graphics chip temperature
- **EDRAM** — the embedded DRAM temperature

Values update every **500ms** while the app is running.

### Fan Control

- View the current fan speed (percentage)
- Increase or decrease speed with the D-Pad
- Minimum **20%** (to prevent overheating)
- Maximum **100%** (full speed)

### Auto Mode (Planned)

- Set a target temperature
- The app adjusts fan speed automatically
- Not yet implemented

## ⚠️ Safety

</div>

- Setting fan speed too low can cause **overheating**.
- The app enforces a **minimum of 20%** to prevent damage.
- Use manual fan control **at your own risk**.
- Read the [Project Ghost Girl Disclaimer](https://github.com/Ghost-Girl-Jailbreak/Project-Ghost-Girl/blob/main/DISCLAIMER.md).
